::: {#b1 .explanation}
Un comando es una orden que se le da al ordenador. Por ejemplo, para listar ficheros se escribe `ls`,
y para cambiar de carpeta se escribe `cd`. El sistema ejecuta la orden y devuelve un resultado.
:::

::: {#e1 .exercise data-number="1"}
Escribe el comando que sirve para crear una carpeta nueva.
:::
