# curriculum-accommodation

Herramienta open source para que maestros de Pedagogía Terapéutica, orientadores y tutores
adapten material didáctico (fichas, ejercicios, exámenes) al perfil de un alumno con
discapacidad, usando su propio agente de IA en local.

El docente siempre revisa y firma. La herramienta quita el trabajo mecánico, no el criterio.
