# Conflict recipes

When two axes ask for opposite things, the corpus must say who wins. This is the
part a model handles least reliably, because both answers look defensible in
isolation and it will pick one silently.

Axes do not explode combinatorially — a learner with three diagnoses is still one
set of ten levels, which is the payoff of profiling by barrier. What does not
resolve itself is **contradiction**: an adaptation that serves one axis and
disables another.

## Resolution order

Apply in order, stopping at the first that decides:

1. **The overlay wins.** If `profiles/<CODE>/adaptations.md` settles it, that is
   the teaching team's decision and it is not reopened here.
2. **`works` and `avoid` win over any recipe.** Observed reality beats theory.
3. **Access beats optimisation.** An adaptation the learner physically cannot
   perceive is not a trade-off, it is an exclusion. A sensory access axis at 3
   outranks a cognitive or attentional preference every time.
4. **Higher level wins.** Where both are the same kind, the more severe barrier
   decides.
5. **If still tied, take the more conservative option** and record the conflict in
   the report so the teacher can settle it — and so consolidation can turn the
   answer into memory.

## Never

Never resolve a conflict silently. An unrecorded conflict is a decision the
teacher never got to make, and it will be made the same wrong way every week.
