# Explicit steps

## What to do

Turn an instruction that assumes planning into a numbered list of actions the
learner can tick off. Each step is one physical action with an observable end.

Start the first step for them where possible — a worked first item removes the
task-initiation barrier, which is usually the real blocker, not the task itself.

State where the answer goes. "Answer the questions" assumes the learner knows
that answers go on the lined space to the right.

## Before

> **7.** Analiza sintácticamente las siguientes oraciones e indica el tipo de
> sujeto.

## After

> **7.** Vas a analizar 3 oraciones. Haz una cada vez.
>
> Para cada oración:
> 1. Subraya el verbo. ☐
> 2. Pregunta "¿quién?" delante del verbo. Lo que responde es el sujeto. ☐
> 3. Rodea el sujeto. ☐
> 4. Escribe debajo si el sujeto es *explícito* u *omitido*. ☐
>
> **Ejemplo ya hecho:** <u>Los pájaros</u> **vuelan** alto. → sujeto explícito
>
> Ahora tú:
> a) Ayer llegamos tarde al colegio.

## Anti-patterns

- **Steps that are goals, not actions.** "Understand the sentence" is not a step.
  "Underline the verb" is.
- **Doing the thinking in the steps.** The steps are a procedure, not the answer.
  If following them mechanically produces the answer without the learner applying
  the concept, you have removed the learning, not the barrier.
- **More than about six steps.** Past that, the list is itself a working-memory
  load. Split the task instead.
- Adding checkboxes to a learner who finds them distracting. Check `avoid`.
