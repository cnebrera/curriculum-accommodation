# Memory format contract

How the system remembers what a teacher taught it, where it is stored, and how
the application loads it without drowning in its own log.

Rationale: [ADR 0004](decisions/0004-memory-is-human-routed.md).
Behaviour: `specs/003-memory/spec.md`.

## The three scopes

| Scope | Question it answers | Location | Shareable |
|---|---|---|---|
| **Learner** | What does *this* learner need? | `profiles/<CODE>/profile.yaml`, `profiles/<CODE>/notes.md` | Never |
| **Practice** | How does *this teacher or school* work? | `memory/house.md` | Only in the school's own fork |
| **Corpus** | What is true for *everyone*? | a recipe change, upstream | Yes, after de-identification |

The teacher routes every item. The agent never guesses the scope: routing a
learner-specific note into the shared corpus is a privacy incident, not a quality
problem.

## Layout

```
profiles/                      git-ignored
├─ roster.yaml                 organisational context, codes only
├─ A3/
│  ├─ profile.yaml             state: axes and qualitative fields
│  ├─ notes.md                 accumulated learner-specific notes
│  └─ adaptations.md           optional: overlay from the official document
└─ archive/2025-26/            closed years; retention clock running

memory/                        git-ignored except README.md
├─ README.md                   what this folder is (committed)
├─ house.md                    practice-level style. Short by design
├─ journal/
│  └─ 2026-09-04-unit4.md      one entry per review session
└─ archive/                    superseded entries, kept for provenance

.rampa/                        machine-owned. The only directory to ignore
└─ index.md                    derived. Regenerated by the application
```

One learner is a directory, not three files with a shared prefix. A teacher with
thirty learners across several groups needs it, and a flat vault stops working in
week two.

Backup is copying two folders. Both are git-ignored, so updating the repository
never touches them.

**This is the teacher's vault, and it is Obsidian-compatible by design** — plain
markdown, one folder, no database. If they open it in Obsidian they get search,
backlinks, mobile and sync without us building any of it; if they open it in
Notepad it still reads. The test that earns this treatment is that these files
are worth something *without* the model: they are the professional record a
teacher already keeps. The corpus is not, and is not exposed this way.

Two rules follow from a human editing these by hand:

- **Prose first, structure light.** Brittle front matter that breaks the pipeline
  on a stray indent is a defect, not the teacher's mistake.
- **Repair, never reject.** The agent normalises what it finds and says what it
  changed. A teacher's note is never invalid.

## Journal entry

```markdown
---
date: 2026-09-04
recipes: [lectura-facil-es, one-task-per-page]
scope: corpus                  # learner | practice | corpus
learner: A3                    # present only when scope is learner
status: open                   # open | promoted | archived
---

## What happened

Splitting the sentence at the comma lost the causal link: «Los bosques
desaparecen. Por eso los animales se van.» became two facts with no connection,
and the learner answered the "why" question with a restatement.

## What should happen instead

Keep the connector and shorten the clauses around it, rather than splitting at
punctuation.

## Proposed change

`lectura-facil-es` anti-patterns: state that connectors carrying causality are
never a split point.
```

**Pattern, never passage.** Describe the shape of what went wrong. Do not paste
the worksheet: it is copyrighted, and it is identifying.

## Learner notes

```markdown
---
learner: A3
updated: 2026-09-04
---

## 2026-09-04 · Checkboxes
Rejected. Reads them as extra tasks and counts them as work to do.
→ added to `avoid`.

## 2026-09-11 · Worked first item
Confirmed twice: with a worked first item she starts unprompted; without it she
waits to be told. Strong effect.
→ already in `works`; raised confidence.
```

Notes are the narrative; `A3.yaml` is the state. When a note becomes stable it is
promoted into the YAML and the note records that it was.

## House style

`memory/house.md` is a **style guide, not a log**. If it grows past roughly two
pages it has stopped being one, and consolidation will say so.

```markdown
# House style

- Body text Arial 14, never below 12.
- Exams always show the mark allocation per item.
- Pictograms from ARASAAC only — the school's boards use that set.
- Never use red for corrections; the department agreed on green.
```

## The adaptation overlay

When the teacher arrives with the learner's official adaptation document, it
becomes `profiles/<CODE>/adaptations.md`: a per-learner recipe set that
**overrides the corpus**. What it does not cover, the corpus fills.

```markdown
---
learner: A3
source: "Learner's official adaptation document, 2026-06"
precedence: override
---

## Response format
All written tasks may be answered orally and transcribed by an adult.

## Assessment
Extra time: 50%. Assessed in a separate room.
```

Overlay statements are **instructions from the teaching team**. The agent follows
them and does not argue with them — with one exception: if an overlay statement
would breach a hard rule (falsifying content, easing an exam's criterion), the
agent flags the conflict and asks, rather than silently obeying or silently
refusing.

## Loading rules

The application must not load its whole history on every run.

| Memory | When loaded |
|---|---|
| `profiles/<CODE>/profile.yaml` | Whenever that learner is the subject |
| `profiles/<CODE>/notes.md` | Same. Consolidated so it stays bounded |
| `profiles/<CODE>/adaptations.md` | Same, if present. Read **before** recipe selection |
| `memory/house.md` | Always |
| `memory/journal/**` | **Never wholesale.** Only entries whose `recipes:` intersect the recipes selected for this run, resolved through `.rampa/index.md` |
| `memory/archive/**` | Never automatically |

`.rampa/index.md` is derived, never hand-edited:

```markdown
<!-- generated by Rampa — do not edit -->
## lectura-facil-es
- journal/2026-09-04-unit4.md (corpus, open)
- journal/2026-10-02-unit6.md (practice, promoted)

## one-task-per-page
- journal/2026-09-04-unit4.md (corpus, open)
```

Building it reads journal front matter and nothing else: deterministic, no model,
per Principle II.

## Consolidation

Append-only logs rot. Consolidation reviews accumulated entries and proposes:

- promoting a repeated learner note into `A3.yaml` (`works`, `avoid`, or an axis
  level that was wrong from the start);
- promoting a repeated practice note into `house.md`;
- proposing a corpus change as a recipe patch, **rewritten as a general statement
  with all learner and material specifics removed**;
- archiving entries that are superseded or were promoted.

Every promotion is confirmed by a human. Nothing is promoted silently, and
nothing reaches the corpus without the de-identification step being visible to
the teacher who is confirming it.

## Export and handover

Export produces a portable bundle in two variants:

- **Full** — for the teacher's own backup, or for handover when a learner changes
  school or teacher. Contains the profile, notes and overlay.
- **Shareable** — practice-level and corpus-level material only, with all learner
  scope removed. This is what goes to a colleague or upstream.

The distinction is enforced by the export, not by the teacher remembering.

**Handover is more than this export.** Moving the files is the easy half; the
hard half is the receiving teacher not believing them more than they should.
Specified in `specs/004-handover/spec.md`.
