# Contract · la presentación en el documento editable

## La promesa

**El mismo alumno recibe la misma accesibilidad por las dos puertas**, salvo en lo que el
formato no puede expresar — que está enumerado aquí y no es discrecional.

| Llega | No llega, y por qué |
|---|---|
| Cuerpo de letra | **Longitud de línea**: el documento no define su página, toma la de ella |
| Interlineado | **Espaciado entre palabras**: ODF no tiene la propiedad |
| Aire entre párrafos | |
| Espaciado entre letras | |
| Tinta | |
| Una tarea por página | |

## Lo que nunca hace

- **Nunca impone una configuración de página.** Es el fichero que ella abre para
  editarlo; su procesador de textos y sus márgenes son suyos.
- **Nunca toca el texto para conseguir un efecto de presentación.** Ni saltos de línea
  manuales para acortar el renglón, ni espacios de más para separar palabras: el texto se
  rompería en cuanto ella cambiara una palabra, que es lo único que este fichero existe
  para permitir.
- **Nunca recibe el perfil.** Lo que cruza es una presentación ya resuelta, igual que en
  el otro renderizador (`007` FR-506).

## Lo que un llamador no debe dar por hecho

- **Que la paridad sea total.** Está acotada arriba, y las dos ausencias son reales: un
  alumno que necesita línea corta no la tiene aquí.
- **Que el registro lo cubra.** No lo cubre: `038` FR-3617 dejó el editable fuera de
  alcance, así que esto **no tiene superficie de revisión automática**. Se mira a mano o
  no se mira.
